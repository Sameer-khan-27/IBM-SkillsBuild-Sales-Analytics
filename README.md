## 📌 Project Overview
This project presents an end-to-end data analytics study on 1,000 retail transaction records across three supermarket branch locations (Yangon, Naypyitaw, and Mandalay). It evaluates category-wise revenue, customer purchasing power (Members vs. Normal walk-ins), and payment channel adoption to generate actionable business intelligence.
